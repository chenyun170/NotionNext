# 文章有用性标准

适用对象：外贸获客情报局（123170.xyz）的全部新文章。
一句话目标：读者读完能说清楚“这件事我该怎么判断”，而不是“有点道理，但我不知道该干什么”。

## 一、每篇至少做到其中两件

不要每篇都凑齐同一套元素。下面三类素材任选两类，写透就行：

1. **一段算账**
   把成本、运费、佣金、退税、汇率或时间折算成一个具体数字。
   数字要能复算，写清楚假设；不确定的地方标明是估算。

2. **一段真实复盘**
   写清楚当时发生了什么、哪一步判断错了、代价是什么。
   没有真实案例就不写，不要编客户名和成交金额。

3. **一段可直接用的原文**
   邮件、WhatsApp 消息、报价备注、合同条款，给完整措辞。
   场景不同可以给两个版本，但不要只写“礼貌说明一下”。

以下内容属于加分项，不是硬性门槛：一张对比表、一份检查清单、一条判断阈值。
表格和清单是为内容服务的，连续叙述能讲清楚时不要硬拆。

## 二、必须避免的写法

| 不要写 | 改成 |
| --- | --- |
| 要重视客户关系维护 | 每季度寄一次新品样品，成本控制在 30 美元以内 |
| 报价要留有余地 | 在成本上加 12%，其中 5% 预留给客户砍价，7% 是净利 |
| 注意风险控制 | 新客户首单不做 T/T 后付，最低 30% 定金或即期信用证 |
| 及时跟进客户 | 报价后第 3 天、第 10 天、第 21 天各一次，第三次换角度 |
| 建立完善的档案 | 一张表五个字段：最后一次联系、他关心什么、卡在哪、下一步、下次联系日 |

另外三条：

- 不要开头写“正在关注某某主题的读者”，也不要结尾写“形成连续的主题理解”。这类句子可以套在任何文章上，等于没有信息。
- 不要在每篇文末放同一段工具推荐。推荐要和这篇文章的问题直接相关。
- 不要为了显得全面，把三个骨架塞进同一篇。

## 三、标题

- 带场景或数字，不超过 30 字。
- 不要“XX 指南”“XX 全攻略”“一文讲透”这类通用后缀。
- 好例子：《客户说“再便宜 5 个点就下单”，这句话怎么接》
- 坏例子：《外贸报价谈判技巧全解析》

## 四、结构：三种骨架轮换，不要每篇一个模子

1200–2500 汉字，3–8 个 H2。按题材选骨架，相邻几篇不要用同一种：

**A. 算账型**（适合费用、报价、关税、物流）
真实单据或场景 → 钱花在哪 → 逐项算一遍 → 哪里最容易算错 → 一张核对表 → 一句判断。

**B. 复盘型**（适合谈判、客户流失、踩坑）
当时的情况 → 做错的判断 → 代价 → 如果重来会怎么改 → 可复用的检查点。
复盘型不要求给清单，也不要求给表格。

**C. 对话型**（适合客户异议、邮件、跟进）
客户原话 → 他真正担心什么 → 三种回法及各自后果 → 推荐哪一种 → 完整回复原文。
对话型可以通篇不用表格。

开头必须有具体场景，不要“随着全球化的发展”。结尾用一句具体判断收住，不要“希望对你有帮助”。

## 五、排版硬门槛（直接决定能不能被搜到）

这一节不是文风问题，是技术问题。违反之后页面在搜索和 AI 回答里的表现会明显变差。

1. **小标题用 Notion「标题 1」**
   本站渲染器把「标题 1」（`heading_1`）输出成 `<h2>`。文章标题本身已经是 `<h1>`，
   正文再用「标题 2」会出现 h1 直接跳到 h3 的大纲断层。
   站内已对“整篇没有标题 1”的老文章做渲染层上提，但新文章仍应直接用「标题 1」。

2. **每篇至少 1 张表格**（算账型、复盘型适用；纯对话型可以省略）
   对比、参数、单据字段、HS 编码、报价构成、工具选型，适合做成表格。
   不要为了凑表格把连续叙述硬拆成表。

3. **每篇至少 2 个权威外链**
   指向官方或一手来源：海关总署、商务部、USITC、UN Comtrade、WTO、
   目标国海关与税务机关官网、平台官方帮助中心。链接文字要写清是什么
   （例如“USITC 的 HTS 查询”），不要写“点击这里”“详见官网”。
   查不到官方来源，就不写具体政策和税率，也不要编链接。

4. **每篇至少 1 条内链指向落地页，而不只是另一篇文章**
   可用的承接页：`/customs-data.html`、`/free-customs-data.html`、
   `/us-importers.html`、`/hs-code-lookup.html`、`/supplier-analysis.html`、
   `/tools.html`、`/turingsearch.html`、`/dingyiyun.html`、`/oraskl.html`。
   放在读者“想马上动手”的那一段，不要全部堆在文末。

5. **标题不超过 30 字**
   超过 32 个汉字，搜索结果里会被截断，点击率直接掉。

## 六、事实纪律

- 引用政策、税率、平台规则，必须能指到官方来源；查不到就不写具体数字。
- 允许写“以某华东港口为例，仅作估算”，但必须标明是估算。
- 不编造客户名、公司名、成交金额、统计数字。
- 涉及会变的价格和时效，优先写成“截至某月”并说明可能变动。

## 七、发布前自检

1. 这篇用的是哪一种骨架？上一篇是不是同一种？如果连续三篇一样，换一种。
2. 算账、复盘、可复制原文，至少占了两样吗？
3. 把“外贸”两个字换成别的行业，这篇文章还成立吗？如果成立，说明写得太空。
4. 读完的人知道下一步做什么吗？
5. 文末推荐和这篇文章的问题相关吗？还是又放了同一套工具链接？
6. 小标题是不是用了「标题 1」，页面上从 h1 到 h2 没有断档？
7. 有没有权威外链和至少 1 条指向落地页的内链？
