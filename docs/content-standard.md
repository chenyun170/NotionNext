# 文章有用性标准

适用对象：外贸获客情报局（123170.xyz）的全部新文章。
一句话目标：读者读完能在今天下午就动手，而不是"有点道理，但我不知道该干什么"。

## 一、每篇必须包含的硬性元素

缺任意一条，就还没写完。

1. **一组具体数字或阈值**
   不是"要多多跟进"，而是"第三次没回复就换话题，隔 7 天，不超过 3 次"。
   可以是行业惯例、你自己的经验值，或者一段算账过程，但必须给数。

2. **一段可以直接复制的原文**
   邮件全文、WhatsApp 消息全文、报价单某一行怎么写、合同条款怎么写。
   不要写"你可以这样回复：礼貌地说明……"，要给字。

3. **一个带代价的失败场景**
   写清楚当时怎么错的、损失了什么（钱、客户、时间、信誉）。
   不要写"我也踩过坑"就完了，要说踩的是什么坑、赔了多少。

4. **一个判断标准**
   帮读者做决定，而不是把选项摆出来。比如"客户年采购量低于 3 个柜，不值得为他开模"。

5. **一个能带走的清单或表**
   3–8 条，能打印出来对着勾。不要每条后面再补一句解释。

## 二、必须避免的写法

| 不要写 | 改成 |
| --- | --- |
| 要重视客户关系维护 | 每季度寄一次新品样品，成本控制在 30 美元以内 |
| 报价要留有余地 | 在成本上加 12%，其中 5% 预留给客户砍价，7% 是净利 |
| 注意风险控制 | 新客户首单不做 T/T 后付，最低 30% 定金或即期信用证 |
| 及时跟进客户 | 报价后第 3 天、第 10 天、第 21 天各一次，第三次换角度 |
| 建立完善的档案 | 一张表五个字段：最后一次联系、他关心什么、卡在哪、下一步、下次联系日 |

## 三、标题

- 带场景或数字，不超过 30 字。
- 不要"XX 指南""XX 全攻略""一文讲透"这类通用后缀。
- 好例子：《客户说"再便宜 5 个点就下单"，这句话怎么接》
- 坏例子：《外贸报价谈判技巧全解析》

## 四、结构

- 1500–2200 汉字，5–8 个 H2。
- 开头必须有具体场景，不要"随着全球化的发展"。
- 至少 2 个列表或编号步骤。
- 结尾用一句具体的判断收住，不要"希望对你有帮助"。

## 五、事实纪律

- 引用政策、税率、平台规则，必须能指到官方来源；查不到就不写具体数字。
- 允许写"以某华东港口为例，仅作估算"，但必须标明是估算。
- 不编造客户名、公司名、成交金额、统计数字。
- 涉及会变的价格和时效，优先写成"截至某月"并说明可能变动。

## 六、发布前自检

逐条问自己，答"否"就回去改：

1. 这篇里有没有至少 3 个具体数字？
2. 有没有一段读者能直接复制粘贴的原文？
3. 有没有一个失败场景，并且写清了代价？
4. 读完的人知道下一步做什么吗？
5. 把标题遮住，这段内容还像是这个网站写的吗？还是像任何一篇外贸文章？
